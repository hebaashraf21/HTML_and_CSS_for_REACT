# HTML and CSS for React 🧱

This repository contains lessons that build a strong foundation in **HTML** and **CSS**—essential skills for anyone learning **React**. Each lesson includes commented HTML and CSS files that explain concepts clearly and practically.

> 📌 This is a part of my React learning journey, focused on mastering the building blocks of the web.

---

## 📁 Folder Structure

HTML_and_CSS_for_REACT/</br>
├── 01-html-elements/</br>
├── 02-css-selectors/</br>
├── 03-box-model/</br>
├── 04-positioning/</br>
├── 05-flexbox-layout/</br>
├── 06-grid-layout/</br>
├── 07-combined-layout/</br>
├── 08-responsive-design/</br>
└── README.md</br>


Each folder contains:
- `index.html`: A self-contained HTML page.
- `style.css`: Styling for the page.
- Comments throughout explaining concepts, behavior, and real use cases.

---

## 📚 Lessons Overview

| Folder                 | Lesson            | Key Concepts                                                                 |
|------------------------|-------------------|------------------------------------------------------------------------------|
| `01-html-elements/`    | HTML Elements     | `div`, `span`, `input`, `form`, `button`, semantic tags                     |
| `02-css-selectors/`    | CSS Selectors     | Element, class, ID, descendant, child, and sibling selectors                |
| `03-box-model/`        | CSS Box Model     | `padding`, `margin`, `border`, `content`, `box-sizing`                     |
| `04-positioning/`      | Positioning       | `static`, `relative`, `absolute`, `fixed`, `z-index`                        |
| `05-flexbox-layout/`   | Flexbox           | `display: flex`, `flex-direction`, `justify-content`, `align-items`, `gap` |
| `06-grid-layout/`      | CSS Grid          | `grid-template`, `fr`, `grid-template-areas`, `gap`                         |
| `07-combined-layout/`  | Flex + Grid       | Hybrid layouts using semantic structure                                     |
| `08-responsive-design/`| Responsive Design | Media queries, mobile-first design, breakpoints                             |

## 🚀 How to Use This Repo

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hebaashraf21/HTML_and_CSS_for_REACT.git
   cd HTML_and_CSS_for_REACT
2. Open any folder and double-click index.html to preview it in your browser.
3. Read the comments in the .html and .css files to understand each part.
4. Experiment and modify the code to reinforce learning.
